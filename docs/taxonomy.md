# 分類・タグ体系

## 地衣類の基本分類

地衣類は菌類と光合成生物（藻類またはシアノバクテリア）の共生体。
分類上は菌類（子嚢菌類が主）に属する。

### 形態による区分（葉状区分）

| 区分 | 説明 | 代表属 |
|------|------|--------|
| 葉状（foliose） | 葉のように平らで、基質から剥がれやすい | *Parmelia*, *Umbilicaria*, *Lobaria* |
| 枝状（fruticose） | 直立または垂れ下がる糸状・枝状 | *Usnea*, *Ramalina*, *Cladonia* |
| 痂状（crustose） | 基質に密着し剥がれない | *Lecanora*, *Graphis* |
| 鱗状（squamulose） | 小さな鱗片状 | *Cladonia*（基部） |

## タグ体系

記録に付与するタグの一覧。`record.md` の `tags:` フィールドに記入する。

### 生育基質タグ
- `substrate:bark` — 樹皮上
- `substrate:rock` — 岩上（種類があれば: `substrate:granite` など）
- `substrate:soil` — 土上
- `substrate:deadwood` — 腐木上
- `substrate:leaf` — 葉面上（葉状地衣）

### 生育環境タグ
- `habitat:forest` — 森林内
- `habitat:open` — 開けた場所（草地・岩場）
- `habitat:coastal` — 海岸付近
- `habitat:alpine` — 高山帯
- `habitat:urban` — 市街地・公園

### 形態タグ（葉状区分を補完）
- `form:foliose` — 葉状
- `form:fruticose` — 枝状
- `form:crustose` — 痂状
- `form:squamulose` — 鱗状

### 生殖構造タグ
- `repro:apothecium` — 盤状子器あり
- `repro:soredia` — 粉芽あり
- `repro:isidia` — 裂芽あり
- `repro:thallus_only` — 栄養体のみ

### 同定確度タグ
- `id:confirmed` — 確定（文献/専門家確認済み）
- `id:tentative` — 暫定（形態から判断）
- `id:unknown` — 不明

## 和名・学名の表記ルール

- 学名はイタリック体: `*Usnea diffracta*`
- 和名は括弧なしで記載: `サルオガセ`
- 同定不明の場合: `*Usnea* sp.`（属まで判明）または `地衣類 sp.`（属不明）
