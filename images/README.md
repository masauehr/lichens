# images/ — 原本画像の管理

## ディレクトリ構成

```
images/
├── README.md      # このファイル
└── raw/           # 写真アプリからエクスポートした原本
    ├── 20260412_001.jpg
    ├── 20260412_002.heic
    └── ...
```

## 命名規則

```
{撮影日YYYYMMDD}_{連番3桁}.{jpg|heic}
例: 20260412_001.jpg
```

## ルール

- `raw/` の原本ファイルは**削除・上書き禁止**（リネームのみ許可）
- カタログ用にリサイズした画像は `catalog/{種ID}/images/` に配置する
- HEIC形式はそのまま保管。GitHub表示が必要な場合のみJPGに変換する

## 写真アプリからのエクスポート手順

1. 写真アプリで画像を選択
2. **ファイル → 書き出す → 変更なしで元のファイルを書き出す**
3. 保存先: このフォルダの `raw/`
4. エクスポート後、命名規則に従ってリネーム

詳細は [docs/workflow.md](../docs/workflow.md) を参照。
